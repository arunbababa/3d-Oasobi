# 3D Oasobi

Three.js + MediaPipe を使った実験的なビジュアルアートプロジェクト

## プロジェクト

### 3d - Hand Dance
手の動きに反応するインタラクティブなビジュアルアート

**機能：**
- リアルタイム手トラッキング（MediaPipe）
- 繊細な指の動きに合わせたパーティクルエフェクト
- 指パッチン検出と特殊エフェクト
- 手の骨格表示と指先トレイル
- Three.js による3D描画

**使い方：**
1. ブラウザで `3d/index.html` を開く
2. カメラへのアクセスを許可
3. 手を動かして楽しむ！

## 技術スタック
- Three.js
- MediaPipe Hands
- Vanilla JavaScript
